# MLH side challenges @ Junction 2026

From the MLH mail to Felix (13 Nov 2026). Prizes in brackets. These are *side*
challenges on top of Junction's own tracks — one project can hit several.

| Challenge | Prize | What they want |
|---|---|---|
| ElevenLabs | Wireless earbuds | Natural/expressive TTS; AI companions, narration, voice-enabled apps |
| Gemini API | MLH swag kits | Google Gemini; chatbots, doc/paper summarisation, code+content generation |
| **Entire** | Mini projector | Git forge for agent-human collab. Use as many primitives as possible: **Sessions** (agent sessions as shareable checkpoints), **Graph** (codebase map, claims −71% tokens vs blind file search), **Brain** (persistent project knowledge via CLI/MCP), **Trails** (issue+PR primitive, agent does task, agent reviews). | Tiger Data | Stream Deck Mini | PostgreSQL + time-series: continuous aggregates, 90%+ compression, real-time dashboards |
| Vultr | Assorted | One-click deploy, scalable compute, Cloud GPUs. Free credits on signup |
| MongoDB Atlas | M5Stack IoT kit | Atlas free tier or $50 student credit |
| DEV Writing Challenge | $100 | Publish the project story on DEV.to after the event |

Promo codes to claim (in the mail, not here): ElevenLabs Q4 2025–Q4 2026, Entire Q4 2026–Q3 2027.

Workshop at the event: **Intro to Google AI Studio** (time announced at opening ceremony / MLH table).

## Why Entire is the one to watch
We already run Warren — multi-agent coordination hub for Claude Code sessions across
machines and people. Entire's Sessions/Brain/Graph are the same problem space, the sponsor
is obscure (likely few submissions), and "measurable token efficiency" is a number we can
actually put on a slide. Research task sent to grokbot `reshercher` to verify the product
is real and usable before we bet on it.

## Cheap stacking candidates
Gemini API, Vultr (deploy there anyway), MongoDB Atlas and the DEV writeup are all low-effort
adds. Solana and Tiger Data only if the project genuinely needs chain or time-series.
